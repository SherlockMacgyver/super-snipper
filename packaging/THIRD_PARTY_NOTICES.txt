FFmpeg 9.0.2, x264 snapshot 0480cb05fa188d37ae87e8f4fd8f1aea3711f7ee,
and zlib 1.3.2
  FFmpeg is a separate executable built for this release from pinned source,
  with GPL-enabled libx264 and zlib. The resulting FFmpeg executable is GPL
  version 2 or later; the individual COPYING files are under licenses/FFmpeg.
  x264 is GPL version 2 or later; zlib uses the zlib license. Source archives,
  exact configure/build recipe and input hashes accompany every binary release
  in SuperSnipper-VERSION-sources.zip at the same release download location.
  No nonfree FFmpeg components are enabled. Windows system libraries are used
  for screen capture. See packaging/build_ffmpeg.py for the build commands.
  https://ffmpeg.org/  https://www.videolan.org/developers/x264.html
  https://zlib.net/

AutoHotkey 2.0.25
  A separate, unmodified AutoHotkey64.exe runs our MIT-licensed hotkey script.
  AutoHotkey is GPL version 2. Its license is licenses/AutoHotkey/license.txt;
  the exact upstream version source archive accompanies the release.
  https://github.com/AutoHotkey/AutoHotkey

Qt 6.11.1, PySide6-Essentials 6.11.1 and shiboken6 6.11.1
  Used under the LGPL version 3 option. Only Qt Core, Gui, Widgets, Network,
  Svg (used by plugins) and the plugins listed in file-manifest.json are included. License texts and
  third-party notices are under licenses/Qt and in the supplied source trees.
  Qt/PySide shared libraries are in _internal/PySide6 and _internal/shiboken6.
  They are not sealed at runtime: users may replace them with ABI-compatible
  modified builds. The application source and build recipe are also supplied
  so a modified dependency can be used to rebuild the whole application.
  Qt base, SVG, image formats and PySide/shiboken source archives for these
  exact versions accompany the release. See their included build instructions.
  https://doc.qt.io/qt-6/licensing.html
  https://doc.qt.io/qtforpython-6/licenses.html

Source and binary releases:
  https://github.com/SherlockMacgyver/super-snipper/releases
The sources ZIP is a required companion to the installer and application ZIP,
not an optional future promise. Binary release publication must include it.

from their documented upstream URLs; this is not a self-contained offline SDK.
